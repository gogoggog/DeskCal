# DeskCal

윈도우·맥 바탕화면에 띄워 두는 월간 달력입니다. 아이클라우드·구글 캘린더와 연결해 PC에서 일정을 보고, 날짜를 더블클릭해 바로 추가합니다. 추가한 일정은 아이폰에도 그대로 들어갑니다. 달력 아래에는 그달 메모를 적어 둘 수 있고, 지난 일정도 검색으로 찾습니다.

## 받기

**[DeskCal 설치 파일 받기 (Windows 10·11)](https://github.com/gogoggog/deskcal/releases/latest/download/DeskCal-Setup.exe)**

설치 없이 쓰려면 [압축 파일](https://github.com/gogoggog/deskcal/releases/latest/download/DeskCal-Windows.zip)을 받아 풀고 `DeskCal.exe`를 실행하세요.

처음 실행할 때 파란 **Windows의 PC 보호** 창이 뜨면 **추가 정보 → 실행**을 누르세요. 개인이 만든 프로그램이라 서명이 없어서 뜨는 경고입니다.

### 맥

- **[애플 실리콘(M1~M5) 맥용](https://github.com/gogoggog/deskcal/releases/latest/download/DeskCal-Mac-arm64.dmg)** · [인텔 맥용](https://github.com/gogoggog/deskcal/releases/latest/download/DeskCal-Mac-x64.dmg)

1. dmg 파일을 열고 **DeskCal**을 **응용 프로그램** 폴더로 끌어 넣습니다.
2. 응용 프로그램에서 DeskCal을 엽니다. "확인할 수 없음" 창이 뜨면 **완료**를 누르고, **시스템 설정 → 개인정보 보호 및 보안** 맨 아래의 **그래도 열기**를 누릅니다. (처음 한 번만)
3. 달력은 바탕화면에 뜨고, 화면 맨 위 메뉴 막대에 달력 아이콘이 생깁니다. 숨기기·설정·종료는 이 아이콘에서 합니다.

그래도 "손상되었기 때문에 열 수 없습니다"가 나오면 터미널에 아래 한 줄을 붙여 넣고 Enter를 누른 뒤 다시 여세요.

```
xattr -cr /Applications/DeskCal.app
```

맥은 자동 업데이트 대신 새 버전이 나오면 달력 위에 알림이 뜹니다. 같은 방법으로 새 dmg를 받아 덮어 넣으면 됩니다.

## 아이폰 캘린더 연결

1. [account.apple.com](https://account.apple.com/account/manage) → 로그인 및 보안 → **앱 암호** → ＋ (이름: DeskCal)
2. 나온 `xxxx-xxxx-xxxx-xxxx` 암호를 복사
3. DeskCal 오른쪽 위 톱니바퀴 → 아이클라우드에 애플 ID와 앱 암호를 넣고 **연결**

애플 ID와 앱 암호는 내 PC에만 암호화되어 저장됩니다.

## 구글 캘린더 연결

톱니바퀴 → 구글 → **구글 계정으로 로그인**을 누르고, 브라우저에서 로그인한 뒤 **허용**을 누르면 됩니다. 처음에 '확인되지 않은 앱' 화면이 나오면 **고급 → DeskCal(으)로 이동**을 누르세요.

개인정보 처리방침: https://gogoggog.github.io/DeskCal/privacy.html

## 월별 메모

달력 아래 한 줄짜리 칸에 그달 메모를 적으면 자동으로 저장됩니다 (Enter로 마침, Shift+Enter로 줄바꿈). 달을 넘기면 그달 메모로 바뀝니다. 경계선을 위로 끌면 메모칸이 넓어지고, 경계선을 두 번 누르면 한 줄 ↔ 넓게가 바뀝니다.

아이클라우드를 연결해 두면 메모가 아이클라우드의 **DeskCal 메모** 캘린더에 저장되어 윈도우와 맥에서 같은 메모를 봅니다. 아이폰 캘린더·minical에서도 매달 1일에 `📝 N월 메모`로 보입니다 (보기 싫으면 그 앱에서 'DeskCal 메모' 캘린더만 끄세요). 자세한 형식은 [docs/data-format.md](docs/data-format.md)에 있습니다.

## 일정 검색

돋보기 버튼 또는 **Ctrl+F**(맥은 **⌘F**)를 누르고 낱말을 적으면 3년 전부터 1년 뒤까지의 일정에서 제목·장소·메모를 찾습니다. 띄어 쓰면 모든 낱말이 들어간 일정만 찾고, 결과를 누르면 그 날짜로 가서 일정을 보여 줍니다.

## 기능

- 대한민국 공휴일, 24절기, 음력 표시
- 날짜 더블클릭으로 일정 추가, 일정 편집·삭제, 끌어서 날짜 옮기기
- 일정마다 색 고르기 (구글 캘린더는 휴대폰 앱에도 같은 색으로 보입니다)
- 물방울 유리(리퀴드 글래스) 디자인 / 기본 디자인 선택
- 라이트·다크 모드, 윈도우 11·맥 배경 흐림 효과
- 위치·크기 잠금
- 월별 메모 (아이클라우드로 윈도우·맥 공유)
- 일정 검색 (제목·장소·메모)
- 윈도우 10·11, 맥(애플 실리콘·인텔)
