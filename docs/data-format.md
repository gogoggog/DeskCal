# DeskCal 데이터 형식과 아이폰 앱 준비

DeskCal은 일정과 메모를 **모두 아이클라우드(또는 구글) 캘린더 안에** 저장합니다. 프로그램만의 서버가 없기 때문에, 나중에 아이폰 앱을 만들어도 같은 데이터를 그대로 읽고 쓰면 윈도우·맥·아이폰이 자동으로 이어집니다.

## 1. 일정

- 표준 캘린더 일정(VEVENT)입니다. 아이폰 기본 캘린더, minical 등 어떤 앱에서도 보입니다.
- **일정마다 고른 색**은 일정 안에 `X-DESKCAL-COLOR:#ff3b30` 처럼 적어 둡니다. 애플 캘린더는 이 값을 무시하고 캘린더 색으로 보여 주지만, DeskCal(그리고 앞으로의 아이폰 앱)은 이 색을 씁니다.
  - 고를 수 있는 8색: `#ff3b30` 빨강, `#ff9500` 주황, `#ffcc00` 노랑, `#34c759` 초록, `#0a84ff` 파랑, `#af52de` 보라, `#ff2d55` 분홍, `#a2845e` 갈색
- 구글 캘린더 일정의 색은 구글의 일정 색 번호(`colorId`)로 저장합니다 (`src/google.js`의 표 참고).

## 2. 월별 메모

| 항목 | 값 |
|---|---|
| 저장 위치 | 아이클라우드 캘린더 **`DeskCal 메모`** (주소 끝이 `/deskcal-memo/`) |
| 한 달 = 일정 하나 | 그달 **1일, 하루 종일** 일정 |
| 파일 이름 · UID | `deskcal-memo-2026-10.ics` · `deskcal-memo-2026-10` |
| 제목 | `📝 10월 메모` |
| 메모 내용 | `DESCRIPTION` (줄바꿈 그대로) |
| 표시 | `X-DESKCAL-MEMO:2026-10` |
| 마지막 수정 시각 | `X-DESKCAL-UPDATED:1761100000000` (밀리초) — 두 기기에서 고쳤을 때 더 늦은 쪽이 이김 |

- 메모 캘린더는 처음 메모를 저장할 때 자동으로 만들어집니다.
- DeskCal 달력에는 이 캘린더를 일정으로 그리지 않습니다 (메모칸에만 보임).
- 아이폰 캘린더·minical에서는 `DeskCal 메모`라는 캘린더로 보이고, 매달 1일에 메모가 하루 종일 일정처럼 보입니다. 보기 싫으면 그 앱에서 이 캘린더만 꺼 두면 됩니다. 반대로 지금 당장 폰에서 메모를 확인하는 용도로 써도 됩니다.
- 메모를 다 지우면 그달 일정도 지웁니다.
- 아이클라우드가 연결되지 않았으면 메모는 그 PC의 `memos.json`에만 저장됩니다.

코드: `src/memo.js` (형식), `src/icloud.js`의 `fetchMemo` · `saveMemo` (저장), 시험: `test/run.js`

## 3. 맥에서 읽고 쓰는 방법

맥용 DeskCal은 앱 암호 대신 맥 기본 캘린더 기능(EventKit)을 씁니다. 같이 들어 있는 작은 도우미(`build/mac/EventKitHelper.swift` → `deskcal-eventkit`)가 맡습니다.

- 처음 켤 때 '캘린더 접근 허용'을 물음. 허용하면 맥 캘린더에 있는 계정(아이클라우드·구글 등)이 모두 보임
- 메모: 이름이 `DeskCal 메모`인 캘린더를 찾아 그달 1일 종일 일정의 메모(notes)를 읽고 씀. 없으면 아이클라우드 계정에 새로 만듦
- EventKit은 `X-DESKCAL-...` 같은 값을 쓸 수 없어서, 맥에서 만든 메모에는 `X-DESKCAL-MEMO` 표시가 없음. 윈도우는 제목(`📝 N월 메모`)과 날짜(그달 1일)로 알아봄
- 일정마다 고른 색은 그 맥에만 기억됨 (캘린더 색은 어디서나 같음)
- 맥 캘린더를 쓰는 동안 아이클라우드 직접 연결(앱 암호)은 쉼 — 같은 일정이 두 번 보이지 않게

## 4. 아이폰 앱을 만들 때

**데이터** — 아이폰에서는 맥과 같은 기본 캘린더 기능(EventKit)으로 위 일정과 메모를 그대로 읽고 씁니다. 앱 암호도 필요 없습니다. 맥 도우미(`build/mac/EventKitHelper.swift`)의 코드를 거의 그대로 가져다 쓸 수 있습니다.

- 일정: 아이폰 캘린더의 일정을 그대로 표시. 색은 `X-DESKCAL-COLOR`가 있으면 그 색.
  (EventKit은 사용자 정의 값을 읽지 못하므로, 일정 색까지 맞추려면 CalDAV로 직접 읽거나 앱 안에 따로 기억해야 합니다. 처음엔 캘린더 색만 써도 충분합니다.)
- 메모: 캘린더 이름이 `DeskCal 메모`인 캘린더에서 그달 1일 종일 일정을 찾아 `notes`(= DESCRIPTION)를 읽고 씁니다. 새로 만들 때 제목은 `📝 N월 메모`.

**사용감 맞추기** — 같은 느낌을 내려고 화면 값들을 한곳(`src/renderer/style.css` 맨 위)에 모아 두었습니다.

| 이름 | 라이트 | 다크 |
|---|---|---|
| 글자 | `#1d1d1f` | `#f5f5f7` |
| 보조 글자 | `#86868b` | `#98989d` |
| 오늘·일요일·공휴일 | `#ff3b30` | `#ff3b30` |
| 선택한 날 | 파랑 8% | 파랑 16% |
| 절기 | `#29a35a` | `#4cd27f` |
| 기본 파랑 | `#0a84ff` | `#0a84ff` |

- 한 달 전체가 한 화면에 보이고, 날짜 칸 안에 일정 제목이 글자로 보임 (점이 아님)
- 날짜 오른쪽 위 숫자, 오늘은 빨간 동그라미
- 하루 종일 일정은 옅은 색 띠, 시간 일정은 색 점 + 제목 + 시각
- 날짜 두 번 누르기(아이폰에서는 길게 누르기) → 새 일정
- 달력 아래 그달 메모
- 일정 검색: 제목·장소·메모, 띄어 쓴 낱말은 모두 들어간 것만, 최근 것이 위

**아이폰에 설치하는 방법** (스토어 등록 없이 나만 쓸 때) — 맥에서 Xcode로 직접 설치합니다. 무료 애플 계정이면 7일마다 다시 설치해야 하고, 애플 개발자 프로그램(연 회비)에 가입하면 1년간 유지됩니다.
