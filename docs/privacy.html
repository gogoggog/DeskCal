DeskCal 개인정보 처리방침

시행일: 2026년 10월 20일

1. 한 줄 요약

DeskCal은 사용자의 정보를 개발자에게 보내거나 서버에 모으지 않습니다. 모든 정보는 사용자의 PC에만 저장되고, 일정은 사용자의 PC와 애플·구글 캘린더 사이에서만 오갑니다.

2. PC에 저장하는 정보

  • 아이클라우드 연결 시: 애플 ID(이메일)와 앱 전용 암호. 암호는 윈도우의 데이터 보호 기능(DPAPI)으로 암호화하여 저장합니다.
  • 구글 연결 시: 구글 계정 이메일과 로그인 유지용 토큰. 토큰은 같은 방식으로 암호화하여 저장합니다.
  • 달력 설정(테마, 창 위치, 표시할 캘린더, 일정 색 등)과 마지막으로 불러온 일정 사본(인터넷이 끊겼을 때 보여 주기 위함)

이 정보는 사용자 PC의 앱 데이터 폴더에만 있으며, 개발자를 포함한 누구에게도 전송되지 않습니다.

3. 구글 사용자 데이터의 이용

구글 계정을 연결하면 DeskCal은 Google Calendar API를 통해 사용자의 캘린더 목록과 일정을 읽고, 사용자가 직접 요청한 일정의 추가·수정·삭제만 수행합니다.

  • 구글 데이터는 달력 화면에 일정을 보여 주고 사용자가 편집하는 용도로만 사용합니다.
  • 구글 데이터를 개발자나 제3자에게 전송, 판매, 공유하지 않으며 광고에 사용하지 않습니다.
  • 구글 데이터를 AI·머신러닝 모델 학습에 사용하지 않습니다.

DeskCal의 Google API 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다.

4. 연결 끊기와 삭제

  • DeskCal 설정에서 연결 해제를 누르면 PC에 저장된 계정 정보가 지워집니다.
  • 구글: 구글 계정 → 서드파티 액세스에서 DeskCal의 권한을 언제든 취소할 수 있습니다.
  • 애플: account.apple.com의 앱 암호에서 DeskCal 암호를 지우면 바로 차단됩니다.
  • 프로그램을 제거하면 설정과 저장된 정보도 함께 지울 수 있습니다.

5. 문의

DeskCal은 개인이 만든 무료 프로그램입니다. 문의는 GitHub에 남겨 주세요.
